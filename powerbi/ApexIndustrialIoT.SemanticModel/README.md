# ApexIndustrialIoT Semantic Model

TMDL source definition for the Industrial IoT Power BI semantic model.

Storage mode: Direct Lake on OneLake.

Source: Fabric Warehouse Gold physical tables.

Security role: Plant RLS.

Connection identifiers are deployment placeholders; do not commit tenant-specific credentials or secrets.

Power BI Desktop can work with PBIP/TMDL project definitions, and the Fabric semantic-model definition APIs support TMDL definitions.
